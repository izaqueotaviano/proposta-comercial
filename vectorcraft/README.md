# VectorCraft 0.10.0 para Windows

Editor de ilustração vetorial gratuito e open source
([storytold/vectorcraft](https://github.com/storytold/vectorcraft), MIT ou Apache-2.0).

## Baixar

| Seu PC | Download |
|---|---|
| **Windows 10/11** (a maioria dos PCs) | [VectorCraft-0.10.0-Windows-x64-Setup.exe](https://github.com/izaqueotaviano/proposta-comercial/raw/main/vectorcraft/VectorCraft-0.10.0-Windows-x64-Setup.exe) |
| Windows em ARM (Snapdragon) | [VectorCraft-0.10.0-Windows-arm64-Setup.exe](https://github.com/izaqueotaviano/proposta-comercial/raw/main/vectorcraft/VectorCraft-0.10.0-Windows-arm64-Setup.exe) |

## Instalar

1. Dê dois cliques no `.exe`.
2. Se aparecer "O Windows protegeu o computador", clique em **Mais informações › Executar assim mesmo**.
3. Siga as 3 telas: **Avançar › Instalar › Concluir**.

Não precisa de senha de administrador. Para desinstalar: *Configurações › Aplicativos › VectorCraft*.
